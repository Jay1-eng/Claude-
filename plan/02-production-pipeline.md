# 02 — Production Pipeline

## Tool stack

Prices are approximate and change; check before subscribing. Start on the **$0 stack** for the first
30 days, then upgrade the voice first (it is what viewers notice most).

| Stage | $0 stack | Upgrade (≈$30–60/mo total) |
|---|---|---|
| Script | This repo's daily pack (generated by the routine) | Same |
| Voice-over | Microsoft Edge "Read Aloud" recorded, or Google Cloud TTS free tier, or CapCut text-to-speech | **ElevenLabs Starter (~$5/mo)** — biggest quality jump per dollar |
| B-roll (real footage) | Pexels.com, Pixabay.com, Mixkit (free, no attribution) | Storyblocks (~$15–30/mo) |
| AI images | Bing Image Creator, Leonardo.ai free tier, Ideogram free tier | Midjourney (~$10/mo) |
| AI video clips | Kling / Luma / Pika free credits; Runway free tier | Runway Standard (~$12–15/mo) |
| Charts / number cards | Canva free (animated number counters, bar charts) | Canva Pro (~$13/mo) for brand kit + background remover |
| Editing | **CapCut desktop** (free: auto-captions, TTS, templates) or DaVinci Resolve | CapCut Pro, or auto-editors Pictory / InVideo AI (~$20–30/mo) if you want "script-in, video-out" |
| Music / SFX | YouTube Audio Library (safe, free) | Epidemic Sound (~$10–18/mo) |
| Thumbnails | Canva free | Canva Pro |
| Upload scheduling | YouTube Studio (schedule up to weeks ahead) | Same |

**Legal/safety:** Only use stock sites with clear free licenses (Pexels, Pixabay, Mixkit). Logos are fine for
commentary/explainer use; do not use other creators' footage. Keep AI-generated "people" generic; never depict
a real executive doing something they did not do.

## The 60-minute Short workflow (do this daily)

| Min | Step | Detail |
|---|---|---|
| 0–5 | Read the pack | Open today's `content/.../day-XX.md`. Read the script aloud once. Fix anything that does not sound like a person talking. Check the **Verify before recording** list. |
| 5–12 | Voice | Paste script into ElevenLabs / CapCut TTS. Export MP3. Listen once; regenerate any line with a mispronunciation. |
| 12–30 | Visuals | Pull 6–9 clips/images using the **Shot list** in the pack: search Pexels with the given keywords; generate 1–2 AI images with the given prompts. Aim for a new visual every 4–6 s. |
| 30–45 | Edit (CapCut) | 9:16 canvas. Drop voice first. Lay visuals to the beats. Add auto-captions (brand font, 3–4 words per line, centered slightly below middle). Add the **big number cards** from the pack. Music at −25 dB. |
| 45–50 | First frame | Make the first frame the hook text, big, over the first clip. |
| 50–55 | Export | 1080×1920, 30 fps, H.264. Under 60 s. |
| 55–60 | Upload | Title, description, hashtags from the pack. Schedule for the pack's posting time. Add to the series playlist. |

## The long-form workflow (Tue + Sat, 2–3 h)

1. **Voice** (20 min): same as above; export as one file, then split by chapter in the editor.
2. **Visuals** (60–80 min): 16:9 canvas. Use the chapter shot lists. Rule: a new visual every 5–8 s;
   a chart or number card at every number in the script.
3. **Edit** (40 min): captions ON (viewers watch muted), chapter title cards at each chapter, B-roll crossfades,
   a subtle zoom-in on static images (CapCut "keyframe" or "auto-zoom" templates).
4. **End screen** (5 min): last 20 s point to the related Short/long-form named in the pack.
5. **Thumbnail** (15 min): Canva, follow brand kit rules, export 2 versions, use "Test & compare."
6. **Upload** (10 min): title, description with timestamps (chapters) from the pack, tags, playlist, schedule.

## Settings that matter in YouTube Studio
- **Altered or synthetic content:** tick "Yes" for AI-generated realistic visuals. This is required and does not hurt reach.
- **Made for kids:** No.
- **Captions:** upload the script as subtitles if auto-captions are poor (improves search).
- **Shorts:** add `#Shorts` in the title or description so it is classified correctly.
- Post Shorts at the pack's suggested time; your audience analytics will refine this after 30 days.
