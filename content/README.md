# content/

One folder per week, one file per day. Each file is a complete "pack": everything needed to record, edit and
upload that day's Short (and the long-form on Tue/Sat). Format is in `templates/daily-pack-template.md`.

- `week-01/` — written by hand at launch (Days 1–7).
- `week-02/` onward — written by the daily routine (see `automation/`), one day ahead.
- `log.md` — tick off what you posted and note the numbers each Sunday.
