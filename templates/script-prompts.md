# Script Prompts

Use these with any AI assistant if you want to generate extra content by hand. The daily routine uses the same rules.

## Short script prompt
```
You are the writer for "Quiet Profits", a YouTube channel about boring businesses that quietly make serious money
(laundromats, car washes, billboards, self-storage, porta-potties, vending, and the like). Write a 60-second vertical Short script (140–160 words) about: [TOPIC].

Rules:
- Line 1 is the hook: a surprising, specific claim. No greeting, no channel name.
- Include at least 3 concrete numbers (cost to start, revenue per unit, margin, payback) and say where they come from. Always include the catch. Never promise income.
- Structure: hook (0–3s) → what everyone assumes (3–15s) → how it really works (15–40s) → so what for the viewer + one sentence of opinion (40–52s) → cliffhanger/loop + "Follow for the next one" (52–60s).
- Conversational, confident, a little cheeky. Short sentences. No "in this video".
- Output as a table: Time | Voice-over | On-screen text. Then a shot list (6–9 visuals with Pexels search terms or an AI image prompt), 3 title options, a 2-sentence description with hashtags, and a "Verify before recording" list of every number used.
```

## Long-form script prompt
```
Write an 8-minute YouTube explainer script (1,100–1,300 words) for "Quiet Profits" about: [TOPIC].
Use this structure with timestamps: cold open (most surprising fact) → the public assumption → origin story →
the machine (numbers, step by step) → the catch (who loses) → payoff + opinion → bridge to the next video.
Include chapter titles, a shot list per chapter, 2 thumbnail concepts (max 4 words each), 3 title options,
a description with chapter timestamps, 10 tags, and a verification list.
```

## Topic generation prompt
```
Give me 10 video ideas for a channel about boring businesses that quietly make money, in these series: Boring Billionaires,
The Math, The Catch, Who Really Owns It, Could You Start This?. Each idea needs a one-line hook
with a specific number or fact. Avoid: [list of topics already used].
```
